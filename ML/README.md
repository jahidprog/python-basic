# Machine Learning (ML)

Use this single folder to learn and practice machine learning algorithms. Keep scripts, notebooks, notes, and datasets together here, and use clear filenames to identify each topic or algorithm.

## Current practice files

- Linear regression: `linear_regression.py`, `simple_linear_regression.py`, `multiple_linear_regression.py`, and related notebooks/scripts.
- Logistic regression: `logistic_regression.ipynb`.
- Naive Bayes: `naive_bayes.ipynb`.
- Supporting material: datasets and `linear_regression_fundamentals.md`.

Add future algorithm practice files directly in this folder, using descriptive names such as `decision_tree.py` or `k_means.ipynb`.
